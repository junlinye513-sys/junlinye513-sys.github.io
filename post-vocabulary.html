英文不卡關：資訊類檢定高頻專業單字與縮寫總整理

📅 115年度更新 🔎 主題：資訊類檢定 / 專業英文

在準備「電腦硬體裝修」、「網路架設」或「電腦軟體應用」等資訊類技術士檢定時，許多考生最擔心的往往不是技術操作，而是考題中大量的英文縮寫、專業名詞與錯誤代碼（Error Message）。只要掌握這些高頻常考的詞彙，在閱讀題目或進行系統除錯時就能大幅提升反應速度，順利拿下關鍵分數！

📌 本篇攻略快速導覽 一、硬體與系統基礎單字 二、網路與通訊必考名詞 三、軟體與資訊安全術語 四、高分背誦技巧與注意事項

一、硬體與系統基礎單字

硬體裝修與作業系統安裝是檢定的基本功，以下單字在 BIOS 設定與硬體故障排除題目中出現頻率極高。

英文簡稱 / 單字 中文翻譯 檢定常考情境說明
Motherboard (MB) 主機板 所有硬體連接的樞紐，常出現在組裝架構與相容性考題。
BIOS / UEFI 基本輸入輸出系統 開機順序 (Boot Sequence)、系統時間調整必經之設定介面。
RAM 隨機存取記憶體 影響系統暫存與運行速度，常考容量單位與插槽規格對應。
SSD 固態硬碟 現今主流儲存裝置，常與傳統硬碟 (HDD) 比較讀寫效能與架構差異。

二、網路與通訊必考名詞

無論是乙太網路壓線測試或是伺服器架設，網路概念始終是各類資訊檢定的命題核心。

英文簡稱 / 單字 中文翻譯 檢定常考情境說明
IP Address 網際網路協定位址 IPv4 與 IPv6 的格式差異、子網路遮罩 (Subnet Mask) 劃分計算。
Router 路由器 負責跨網段資料傳輸與路徑選擇，網路架設檢定必考的核心設備。
Protocol 通訊協定 例如 TCP/IP、HTTP、FTP 等，為網路上資料傳輸所遵循的標準規範。
Bandwidth 頻寬 網路傳輸速率的測量指標，常考單位換算（如 Mbps 與 MB/s 的區別）。

三、軟體與資訊安全術語

隨著資安意識抬頭，系統防護、權限控管及加密機制已成為學科測驗的新重點趨勢。

英文簡稱 / 單字 中文翻譯 檢定常考情境說明
Firewall 防火牆 用於阻擋惡意網路連線與封包過濾，常見於作業系統安全設定考題。
Malware 惡意軟體 統稱包含病毒 (Virus)、木馬程式 (Trojan) 等有害系統的泛稱。
Encryption 加密 保護資料傳輸與儲存安全的重要技術，常與解密 (Decryption) 結合考出。

四、高分背誦技巧與注意事項

準備專業英文與一般生活英文不同，掌握全名對照與實際情境聯想是最有效率的方法。

💡 備考要點： 許多單字在考題中會以縮寫形式出現，建議先理解對應的英文全名，記憶起來會更加深刻。例如看到「HTTP」，若知道其全名為 HyperText Transfer Protocol，就能馬上聯想到超文字與網頁傳輸的關聯。
⚠️ 考場常見失分陷阱：
  • 大小寫代表不同意義： 例如 b (bit / 位元) 與 B (Byte / 位元組) 在計算儲存容量或網路傳輸速率時，兩者相差整整 8 倍！
  • 避免機械式死背： 應嘗試將英文單字直接與「實體硬體設備」或「操作介面畫面」做連結，大腦記憶會更持久。
